# PhysioSentinel Gait Version 161

Versión derivada de V160 que añade validación anatómica cerrada ante fallos
para pelvis y pies. Descomprime el ZIP y conserva todos los archivos en la misma
carpeta. El punto de entrada de Streamlit continúa siendo `streamlit_app.py`.

La carga del atlas Denver y del NPZ se mantiene igual. Antes del primer render,
la interfaz muestra el resultado del QC anatómico V161.
